CASE STUDY

Лендинг для бизнеса.

Демо-лендинг кофейни «Зерно»: меню, отзывы и онлайн-бронь столика. Проект вымышленный, сделан как пример работы.

Роль

Дизайн и разработка

Стек

HTML / CSS · JavaScript

Год

2026

Ссылка

Открыть демо ↗ Код { }

Задача

Показать, как выглядит современный сайт для небольшого заведения: рассказать о кофейне, представить меню с ценами, собрать отзывы и принимать заявки на бронь столика прямо со страницы.

Решение

Одностраничный сайт на чистых HTML, CSS и JavaScript, без фреймворков. Тёплая тёмная палитра и шрифты Playfair Display и Inter. Меню переключается по вкладкам (кофе, чай и напитки, выпечка и десерты) и строится из данных на JavaScript, поэтому цены легко менять. Блоки плавно появляются при прокрутке, а на телефоне работает меню-бургер.

Результат

Готовая демо-страница, которая аккуратно выглядит на телефоне и на компьютере и учитывает настройку «уменьшить движение». Весь сайт лежит в одном файле и не использует сторонних библиотек, только шрифты. Форма брони работает в демо-режиме и ничего не отправляет; для реального заведения её можно подключить к почте или Telegram.

Что внутри

  • Меню с тремя вкладками и ценами
  • Отзывы гостей
  • Форма брони с проверкой имени и телефона
  • Адаптивная вёрстка и мобильное меню
  • Плавное появление блоков при прокрутке

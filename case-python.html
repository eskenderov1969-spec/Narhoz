CASE STUDY

Приложение на Python.

Консольное приложение на Python для учёта личных расходов: записывает траты, считает статистику, следит за месячными лимитами и выгружает данные в CSV. Демо запускает настоящий Python прямо в браузере. Данные вымышленные, проект сделан как пример работы.

Задача

Сделать небольшое полезное приложение на Python, которым удобно пользоваться из терминала: быстро записать трату, увидеть, куда уходят деньги, и вовремя заметить, что лимит на месяц почти исчерпан.

Решение

Одно приложение в одном файле, только стандартная библиотека Python. Суммы считаются через Decimal, поэтому нет ошибок округления с копейками. Команды разбирает argparse, данные хранятся в JSON, выгрузка идёт в CSV. Логика (журнал расходов, расчёты, вывод) отделена от командной строки, поэтому тот же файл запускается и на компьютере, и в браузере. Для демо страница загружает Pyodide, то есть Python, собранный в WebAssembly, и выполняет настоящий tracker.py. Ошибки ввода превращаются в понятные подсказки, а не в трейсбэк.

Результат

Работающее приложение, которое можно попробовать без установки: нажмите demo, затем stats и budget. Код можно посмотреть на сайте кнопкой «Код» или скачать и запустить командой python tracker.py list. Демо хранит записи только в браузере. Во время разработки я нашёл разницу в поведении argparse между версиями Python и сделал разбор даты устойчивым к ней, поэтому приложение одинаково работает в версиях 3.12 и новее.

Что внутри

  • Команды add, list, delete, stats, budget, export, demo
  • Статистика по категориям и месяцам с текстовыми диаграммами
  • Месячные лимиты и предупреждение о превышении
  • Деньги через Decimal, хранение в JSON, выгрузка в CSV
  • Запуск на компьютере и в браузере из одного файла
